## 运行

需要 Python **3.10+**：

```sh
git clone https://github.com/PersevereW/travel2HK.git
cd travel2HK
python3 server.py
```

打开 http://127.0.0.1:8766 。数据库自动保存在 `storage/travel.sqlite3`。首次只有预留的 `qhw` 管理员，手帐仍为初始数据。

```sh
# 对外监听；实际发布由HTTPS反向代理转发到服务端口
python3 server.py --host 0.0.0.0 --port 8766
# 可将数据库设在持久化磁盘
python3 server.py --db /absolute/persistent/path/travel.sqlite3
```

前端和 `/api/*` 使用同一域名。**GitHub Pages、直接双击 HTML 或 `python3 -m http.server` 仅能预览初始内容，不提供跨访客的用户和保存服务。** 仓库 push 不等于已部署 Python 服务。使用持久化存储并备份数据库；数据库、会话、源码和 research 不由静态接口公开，数据库也不会提交到 Git。

## 用户与保存

- 默认访客看到初始攻略。编辑行程、勾选、写备注、预算、住宿偏好和导入等写入前，都要求输入用户名。
- 用户名最多8个字符，支持字母、数字、汉字、下划线与短横线；做 NFKC 规范化并转小写。最多10个用户名，**包含预留的qhw**；满额后已有用户仍可登录。
- 首次登录建立空间，后续同名登录恢复自己的手帐；各用户数据存在 SQLite 独立记录，跨设备同名可读同一份。切换 / 退出前等待保存，退出后恢复初始攻略。
- `qhw` 登录后才出现第08页「用户管理」。服务端再次校验权限，普通用户不能列出或删除用户；管理员管理用户名和时间，不读取他人手帐。删除会移除该用户数据和全部会话、释放名额；qhw不可删除。
- 按要求采用**仅用户名、无密码**登录，因此这是数据分区，不是身份验证：知道用户名的人能进入相应空间，知道qhw的人也能成为管理员。不要存证件、密码或隐私；如需真实访问控制，公开上线前应增加身份认证。
- 自动保存有400ms合并间隔，保存状态显示当前用户名；失败时保留本页修改，可重试或导出。关闭页面时未保存会提示。
- 同一用户多标签页有版本冲突检测；共享cookie在另一标签切换用户后，旧页面的写入也会被拒绝，避免串写。冲突时先导出，再刷新 / 导入。
- JSON导入只覆盖当前用户，前后端均检查字段及长度；导出可用于个人备份。清理浏览器不会删除服务端记录，7天会话过期后重新输入用户名。
- 旧v1/v2/v3浏览器数据不自动显示给任何用户，也不自动迁移到公共初始攻略。旧localStorage原值保留；原设备登录qhw可显式导出旧本机备份，再按需导入v3。v1/v2备份继续仅作旧路线参考。
