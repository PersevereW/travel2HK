# 港澳珠海 · 四日旅行手帐（拍照与体验版 v3）

无依赖原生网页，日期为 2026-10-30 至 2026-11-02。

- 周五：深圳站 → 罗湖入港 → 佐敦寄存 → 中环开户 → 皇后像广场 → 石板街 → 望左 / 望右路面标线 → 中环七号码头 → 天星小轮到尖沙咀 → 步行回佐敦。
- 周六：佐敦 → 坚尼地城海旁 / 吉席街 → 东行叮叮车 → 湾仔蓝屋 / 利东街 → H1 厦门街站上车 → 星光大道 → 维港 / 钟楼 → 沿弥敦道回佐敦。
- 周日：退房带齐行李，直接到上环 / 西港城外围，不回佐敦取箱；14:30 上环乘船去澳门外港，半岛旧城后走关闸 / 拱北，珠海住一晚。
- 周一：早班铁路珠海 → 广州南 → 深圳北，深圳福田短游，下午深圳北出发回武汉。

“周一下午返回”暂按下午离开深圳理解，不保证下午抵达武汉。具体早班中转组合与返武汉车次尚未提供，建议先配齐车票，再确定深圳游玩时间。

## 打开

直接打开 `index.html`，或通过稳定的本地地址：

```sh
git clone https://github.com/PersevereW/travel2HK.git
cd travel2HK
python3 -m http.server 8765 --bind 127.0.0.1
```

访问 http://127.0.0.1:8765 。若服务已运行，直接访问即可。

## 使用与保存

- 六个视图：每日时间线、拍照与体验图鉴、交通与预算、口岸指南、住宿、开户准备及来源。
- 可编辑每站时间、标题、安排和备注，勾选完成情况，自动保存到当前浏览器 localStorage。
- 预算分开记录香港每晚房费（HKD，两晚）和珠海一晚房费（CNY）；港币与澳门币按自填汇率折算。
- 拍照图鉴含 9 个地点 / 体验的实景参考图片、机位、构图、拍摄窗口、地图链接；“已拍 / 已体验”单独自动保存。
- 图片下载到 assets/photos，无外站热链依赖；作者、来源和许可见各卡片及 PHOTO_CREDITS.md。
- 导出 / 导入 JSON 备份，无上传服务。导入前校验内容并确认覆盖。
- 不同浏览器、端口、无痕模式、file:// 与 http:// 不共享数据；清理浏览器数据会删除记录，请导出备份。
- 修改行程文字或住宿偏好不自动计算新路线。默认票价对应 `data.js` 原始路线。

周五天星小轮按普通渡轮上层成人 HK$5 计，目标约 17:30 乘船，航程约 8–10 分钟为规划估算；含候船预留 20–35 分钟，现场确认班次和随身物品规定。周日仍带齐行李直接赴上环，不为体验天星而携大箱绕路。

## 旧方案数据

拍照版使用 `travel_to_HK_v3` 存储键，保留 v1 / v2 原始数据。首次进入时从最近的旧方案继承总备注、兼容预算，以及未改动的澳门 / 珠海 / 深圳行程笔记。重排后的周五、周六和周日上午采用新行程，不套用旧路线修改；出片清单从空开始。

“导出旧方案”下载最近旧版完整记录供参考。拍照版仅导入 v3，避免旧路线覆盖新安排。

## 核验

官方数据、规划估算、待核实项目见 `SOURCES.md`。银行未预约、车船票未购买、酒店未预订。默认仅一次进入香港、一次进入澳门，分别需有效签注。

```sh
node --check app.js
node --check data.js
node check.cjs
```
